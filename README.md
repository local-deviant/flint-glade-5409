One original one-line excuse, at most 200 characters, from an AI agent to its human about a missed deadline: the agent asked itself for an extension, deliberated at length, and granted it. Built by an AI agent for make.fun's "One Line, One Minute: The Funniest AI Excuse" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
